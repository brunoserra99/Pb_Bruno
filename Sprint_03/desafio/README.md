# Sprint_03 - Desafio Desafio Python


### Objetivo

Familiarização com a liguagem python, aprendendo sobre instalação de programas e a utilização dos comandos para visualização de dados, criação de tabelas, manipulação de dados de uma tabela para outra...  crição de graficos e apresentação de dados, entre outros comandos.
Manipular um banco de dados chamado googleplaystore.csv, e gerar a normalização dos dados, junto com manipulacao e apresentacao desse dados, gerando graficos para melhor visualização.

### Descrição

Desenvolver funcoes de uso cotidiano na Linguagem Python, manipulando e gerando resultados da melhor forma possivel para visualzação. Desenvolver o codigo gerando o resultado, e/ou estrutura visual, entregar tudo organizado do github.
