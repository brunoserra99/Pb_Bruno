# Sprint_09


Ao final da Sprint_09, me aprimorei mais em python onde também já foi assunto da sprint_03 e sprint_04, sprint_05, sprint_06 e sprint_07, sprint_08.
Sendo python um assunto que já foi estudado em outras oportunidades mesmo como iniciante... Hoje posso dizer que obtenho um conhecimento entre iniciante e intermediário.

Esta semana não foi apresentado os cursos Aws, porem sigo com estudos para certificação, e me aprimorando e preparando para obtenção da aprovação no exame Aws certified cloud practitioner.

Nesta sprint realizamos exercícios para modelagem da camada refined, onde em um data laker os dados ficaram a disposição para as analises e extração de insights. Os dado foram estruturados seguindo o principio da modelagem multidimensional, para consultas de diferentes perspectivas. E para a geração destes desafio basicamente foi utilizados o serviços aws, glue onde o próprio script que foi gerado dentro do serviço realizou todo o procedimento. Utilizando pyspark, e comandos Sql para realizar alguns views.

Todo o conteúdo do manipulação de dados se deu da camada Trusted para a Refined. lembrando que tal ingestão de arquivos foi realizada por script rodando dentro da Aws.

A exploração mais pratica do laboratório Aws, sobre algumas funções e funcionalidades que a Aws, s3, Athena, lambda, Glue e Iam demonstram aplicações mais realistas e as necessidades da vida real, que são desenvolvidas nos laboratórios da aws, e o dia dia do desenvolvedor.

E a manipulação de dados dentro da Aws movendo os arquivos da Camada Trusted para a camada Refined, coloca em evidencia a pratica, e a vivencia junto as funcionalidades do dia dia do analista de dados.

Essa duas semanas assistindo aos vídeos, e buscando outras formas de aprendizados, assim como o exercícios, foi muito bom para participar mais da tecnologia que a Aws oferece.
