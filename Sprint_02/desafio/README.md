# Sprint_02 - Desafio Script Sql 

## Script Sql

### Objetivo

Familiarização do SQL, aprendendo sobre instalação de programas e a utilização dos comandos para visualização de dados, criação de tabelas, manipulação de dados de uma tabela para outra...  e outros comandos.
Manipular um banco de dados chamado concessionária.sql, e gerar a normalização dos dados, a modelagem relacional, e modelagem dimensional, criar view para facilitar buscas e/ou consultas com maior rapidez

### Descrição

Desenvolver funcoes de uso cotidiano na trabalho com banco de dados, onde normalize e crie estruturas para facilitar a manipulacao de dados com maior agilidade e rapides pelo sistema, melhorando o desempenho e a entrega de resultados. Desenvolver o codigo gerendo a normalizacao, a (s) modelagem realcional, e dimencional, gerar a imagem da estrutura visial (diagrama das tabelas) e entregar tudo organizado do github.

### Etapas para realização do desafio

* Assistir as trilhas sobre o conteúdo
* Baixar arquivos necessários
* Realizar os excercicio (praticar)
* Criar e desenvolver o script
* Iniciar o script do desafio
* Realizar teste e verificar as funcionalidades 
* Gerar a imagem de estrutura
* Finalizar no repositorio do github
